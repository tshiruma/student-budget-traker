# student-budget-traker
A Java command-line application built to track student allowance income, fast-food expenses, and monthly remaining balances while practicing core Git workflows

## Features
- Input monthly allowance or bursary funding.
- Track common student deductions (like fast-food and delivery runs).
- Calculate and display remaining balances.

## Tech Stack
- **Language:** Java
- **Tools:** Android Studio, Git, GitHub
